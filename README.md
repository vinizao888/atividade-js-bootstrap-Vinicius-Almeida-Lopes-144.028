# Painel de Estudos

## Sobre o projeto

Fiz uma página sobre estudos para praticar HTML, Bootstrap e JavaScript. Escolhi esse tema para organizar tarefas e notas.

## Interface

A página tem três cards, uma mensagem, um botão e uma barra com o nome do projeto.

## Bootstrap

Usei o Bootstrap para organizar os cards e deixar a página adaptada para diferentes telas.

## Variáveis

Usei `const`, `let` e `var` para praticar a criação de variáveis no JavaScript.

## Tipos de dados

Pratiquei `string`, `number`, `boolean` e `null` para entender os diferentes tipos de valores.

## Operadores

Fiz cálculos de soma, subtração, multiplicação e divisão, além de comparações com números.

## Template literals

Usei template literals para criar mensagens com informações das variáveis.

## Condições

Usei `if` e `else` para verificar a média do aluno e se ainda existem tarefas pendentes.

## Desafio integrador

Calculei as tarefas pendentes e a porcentagem de tarefas concluídas. Também criei uma mensagem com o resultado.

## Maior dificuldade

Minha maior dificuldade foi organizar os elementos da página usando o Bootstrap.

## Como resolvi

Procurei exemplos e fui ajustando o código até conseguir organizar os cards e adaptar a página para diferentes telas.
